# 摸鱼小窗 (PipReader)

一个可以藏在电脑角落的桌面小窗，支持网页浏览、视频播放、在线小说阅读、本地TXT阅读，具备老板键一键隐身、窗口置顶、透明度调节、视频倍速、分屏摸鱼等功能。

> 工作累了？打开小窗，摸一会儿鱼。

---

## 功能特性

### 核心功能
- **网页浏览**：内置浏览器，任何网站都能在小窗里打开
- **视频播放**：支持抖音、B站等视频网站，倍速播放（1x/1.5x/2x/3x）
- **在线小说**：内置小说搜索，多书源自动搜索，支持目录阅读、全本TXT导出
- **本地TXT**：支持本地TXT小说阅读，字体可自定义
- **分屏摸鱼**：左边视频右边小说，同时进行，分隔条可拖动
- **老板键**：一键隐身，窗口和任务栏图标全消失，再按恢复

### 体验优化
- **窗口置顶**：永远在最前面，不会被别的窗口挡住
- **透明度调节**：Alt+鼠标滚轮 或 按钮调节，越透明越隐蔽
- **一键静音**：静音/恢复一键切换
- **收藏夹**：收藏常用网站，一键打开
- **历史记录**：自动记录浏览历史
- **去广告**：内置广告拦截，减少网页广告干扰
- **快捷网站**：自定义快捷网站，一键访问
- **自定义热键**：老板键等快捷键可自定义，按一下输入框直接按键即可
- **背景自定义**：支持自定义背景图片，也可使用纯白背景
- **窗口位置记忆**：自动记住窗口大小和位置，下次打开恢复

### 稳定性与安全
- **无障碍点击**：网页按钮被遮罩挡住或站点吞掉点击事件时，自动穿透补偿（更多菜单可切换：智能穿透 / 强穿透 / 关闭），iframe 内同样生效
- **倍速全站生效**：倍速注入覆盖所有 iframe 和 Shadow DOM，0.5x~4x 调快调慢都正常，1x 也会主动重置
- **单实例锁**：防止多开
- **崩溃自愈**：渲染进程或webview崩溃自动重载
- **配置损坏恢复**：配置文件损坏自动备份恢复
- **全局错误兜底**：uncaughtException / unhandledRejection 全局捕获
- **权限默认拒绝**：网页请求摄像头、麦克风等权限默认拒绝
- **webview安全加固**：从主进程强制安全设置，防止XSS获取Node权限
- **UA伪装**：去掉Electron标识，防止网站拒绝

## 快速开始

### 下载使用
1. 下载最新的 `PipReader.exe`
2. 双击运行，无需安装
3. 第一次打开会看到欢迎页面，上面有快捷键说明

### 从源码运行
```bash
# 克隆项目
git clone <仓库地址>
cd PipReader

# 安装依赖
npm install

# 开发模式运行
npm start
```

### 打包成exe
```bash
npm run build
# 产物在 dist-out/PipReader.exe
```

## 使用说明

### 顶部按钮（从左到右）
| 按钮 | 功能 |
|------|------|
| 主页 | 回到欢迎页面 |

| 地址栏 | 输入网址，按回车打开 |
| 前往 | 打开地址栏里的网址 |
| 搜索 | 搜小说（在线搜书，直接在窗里看） |
| 收藏 | 收藏当前网页，下次一键打开 |
| 历史 | 看过的网页记录 |
| 分屏 | 左边看视频，右边看小说，同时进行 |
| 置顶 | 窗口永远在最前面 |
| 透明度 | 调窗口透明程度 |
| 倍速 | 视频加速播放 |
| 静音 | 一键静音/恢复 |
| 老板键 | 一键隐身/显示 |
| 设置 | 打开设置面板 |

### 快捷键
| 快捷键 | 功能 |
|--------|------|
| F12（默认，可自定义） | 老板键：一键隐身/显示 |
| Ctrl + 鼠标滚轮 | 放大/缩小网页内容 |
| Alt + 鼠标滚轮 | 调窗口透明度 |
| Esc | 关闭各种下拉菜单 |

> 注意：除了老板键，其他快捷键只在小窗里生效，不影响在其他软件中打字。

### 看小说的三种方式

**方式一：在线搜小说（推荐）**
1. 点顶部搜索按钮
2. 选择"书源解析"模式
3. 输入小说名字，点搜索
4. 搜到后点小说名字，查看章节目录
5. 点哪章看哪章
6. 想下载全本？点目录底部的"导出全本TXT"按钮

**方式二：快速搜索（跳转到网站看）**
1. 点搜索按钮
2. 选择"快速搜索"模式
3. 选一个小说网站（七猫、起点、晋江等）
4. 输入名字，点搜索
5. 直接在网站里看

**方式三：本地TXT**
1. 把 .txt 文件直接拖到小窗里
2. 自动打开，翻页看就行
3. 字体可以在设置里改

### 分屏摸鱼
1. 先打开一个视频网站
2. 点顶部分屏按钮
3. 左边是视频，右边自动打开小说阅读器
4. 中间分隔条按住拖动可调左右大小
5. 再点一次分屏按钮退出分屏

### 设置说明
点顶部设置按钮打开设置面板。每个分类右边都有"恢复默认"按钮，不怕改坏。

| 分类 | 能改什么 |
|------|---------|
| 背景图片 | 换窗口背景图，也可以用纯白背景 |
| 快速搜索源 | 管理快速搜索的小说网站，加/删/改 |
| 顶栏按钮 | 选择哪些按钮显示在顶部 |
| 热键 | 改老板键等快捷键 |
| 外观 | 改窗口标题、小说字体 |
| 快捷网站 | 管理顶部快捷网站 |
| 小说搜索源 | 管理书源，导入/导出JSON |
| 其他 | 媒体控制栏等开关 |

## 技术栈

- **Electron 33**：桌面应用框架
- **原生 JavaScript**：无前端框架，轻量高效
- **webview 标签**：内嵌浏览器
- **@cliqz/adblocker-electron**：广告拦截
- **xpath + @xmldom/xmldom**：小说网页解析
- **iconv-lite**：编码转换
- **electron-builder**：打包工具

### 项目结构
```
PipReader/
├── main.js              # 主进程：窗口管理、IPC、小说接口、稳定性
├── preload.js           # 预加载：IPC桥接
├── index.html           # 主界面：所有UI和渲染进程逻辑
├── webview-preload.js   # webview预加载：链接拦截、快捷键
├── txt-reader.js        # TXT小说阅读器
├── welcome.html         # 欢迎页
├── bs.json              # 书源配置（binbyu/Reader格式）
├── novel-sources.json   # 统一小说搜索源配置
├── package.json         # 项目配置
└── build/
    └── icon.jpg         # 应用图标
```

## 更新日志

### 2026-09-09 · 无障碍点击与全站倍速版

**网页无障碍（核心更新）**
- ✅ **无障碍强制点击**：参考 microsoft/vscode PR#76148 与强制点击类 userscript 的通用方案实现。点击时用 `elementsFromPoint` 取完整元素栈（含 open Shadow DOM），对被透明遮罩挡住/被站点吞掉事件的真实按钮派发完整事件序列（pointerdown→mousedown→pointerup→mouseup→click）。在 preload 最早阶段以 window capture 注册，站点无法先于我们拦截
- ✅ 三档开关（更多菜单）：**智能穿透**（默认，仅穿透"透明+无文字+背景alpha<0.2+无交互后代"的拦截层，不误伤正常弹窗 backdrop）→ **强穿透**（点击未落在交互链上一律补偿重播）→ **关闭**；状态记忆，每次导航自动重发
- ✅ **子框架注入**：webview 开启 `nodeIntegrationInSubFrames`，点击修复、按键、滚轮、倍速在 iframe 内同样生效（腾讯视频等播放器在 iframe 里的站点是最大受益者）

**倍速修复**
- ✅ 倍速递归注入所有 iframe + Shadow DOM + MutationObserver 守卫，播放器自己改倍速会被立即夺回
- ✅ 修复"只能调快不能调慢"：0.5x 慢放正常，切回 1x 主动重置

**去广告纠错**
- ✅ 移除误杀域名：`bdstatic.com`（百度全站 CSS/JS）、`tbcdn.cn`（淘宝静态资源）、`segmentfault.com` 等——之前这些站的页面会裸奔成 HTML

**弹窗处理**
- ✅ 弹窗型站点（`window.open`）不再弹新窗：真实网址原地打开；`about:blank` 空壳弹窗直接忽略，避免白屏顶掉当前页
- ⚠️ 已知限制：个别"先开空窗再写入内容"或 DRM 版权站点接不住，用浏览器打开后复制播放页链接贴进地址栏即可（见常见问题）

**其他**
- ✅ 新增本地验证页 `测试页面-遮罩按钮.html`（穿透逻辑离线自测）
- ✅ 欢迎页提示"使用前先看说明"；使用说明.txt 补充按钮点不动/播放页打不开的处理办法

## 常见问题

**Q：老板键按了没反应？**
A：可能跟别的软件快捷键冲突了，去设置里换一个键试试。

**Q：网页里的链接点不开？**
A：所有链接都会在小窗里打开，不会弹新窗口。如果打不开，试试刷新页面。

**Q：单个网页一直打不开怎么办？**
A：小窗只有一页，个别网站点播放/点链接会往新标签页跳，接不住。解决办法很简单：
1. 用正常浏览器（Chrome/Edge）打开该网站，点到你要看的播放页
2. 把浏览器地址栏里的链接复制下来
3. 回到小窗，把链接贴进地址栏回车 —— 照样能用
（本机已验证：浏览器里能打开的播放页，链接贴进小窗一样可以放）

**Q：网页里的按钮点不动？**
A：开更多菜单里的「无障碍点击」（默认智能穿透，不行切强穿透）。若个别站点仍不行，参考上一条的"复制链接"办法。

**Q：视频倍速不管用？**
A：已支持全站倍速（含 iframe 里的播放器），0.5x 慢放到 4x 快放都能调。如果个别网站播放器自己改回倍速，程序会自动夺回。

**Q：小说搜不到？**
A：多试几个关键词，或者用"快速搜索"模式直接去网站搜。书源可以在设置里导入更多。

**Q：窗口太透明了看不清？**
A：点顶部透明度按钮调回来，或者用 Alt+鼠标滚轮调。

**Q：怎么彻底关闭？**
A：右键任务栏里的小窗图标，选"退出"。或者直接关窗口也行。

**Q：窗口跑到屏幕外找不到了？**
A：程序会自动检测窗口位置是否在当前显示器上，如果不在会自动居中。
